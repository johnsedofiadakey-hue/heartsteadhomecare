# Heartstead QR code

Scans to https://heartsteadhomecarenj.com. Coffee brown (#4A1E02) on ivory (#FBF6EA) with the house-and-heart emblem.

- `heartstead-qr-card.png`: branded card with logo, call to action, web address and phone
- `heartstead-qr.png`: QR code only, 2400×2400
- `heartstead-qr.svg`: vector, for professional print

Print at least 2 cm (0.8 in) wide on a light background.

Regenerate: `npm i --no-save qrcode` then `node brand-assets/qr/make-qr.mjs` (uses the repo's sharp).
